# 스택과 큐

## 스택과 큐 - 스택
- 스택이란
	- 스택은 모든 원소들의 삽입과 삭제가 리스트의 한쪽 끝에서만 수행되는 제한 조건을 가지는 선형 자료구조
	- 스택은 나중에 들어간 원소가 제일 먼저 빠져나오므로, LIFO(Last In First Out)라고도 한다
- ![[image-이산 수학 특강-35.png]]
	- push
		- 자료를 넣는 것
	- pop
		- 자료를 꺼내는 것
	- top
		- 자료의 삽입과 삭제가 일어나는 위치
- Q. 2025 초등부 1차 3번

## 스택과 큐 - 큐
- 큐의 개념
	- 한쪽 끝으로 자료를 넣고, 반대쪽에서는 자료를 뺄 수 있는 선형구조
	- 가장 먼저 들어간 원소가 제일 먼저 빠져나오므로 FIFO(First In First Out)라고도 한다
- ![[image-이산 수학 특강-36.png]]
	- push
		- 큐의 입구(back)에서 자료를 넣는 것
	- pop
		- 큐의 출구(front)에서 자료를 꺼내는 것
	- front
	- back
