# 디닉 알고리즘

- 실전 최대유량 기본 알고리즘
- [\[Algo\] 유량 네트워크 (4) 디닉 알고리즘(Dinic's Algorithm)](https://velog.io/@frog_slayer/Flow-Network-4)

```text
while BFS로 레벨 그래프를 만들 수 있으면:
    while DFS로 레벨 그래프 안에서 유량을 보낼 수 있으면:
        가능한 만큼 유량을 보낸다.
```

## 요약
1. BFS로 `S`에서 각 정점까지의 거리를 구해 **레벨 그래프**를 만든다.
2. 레벨이 정확히 `+1` 증가하는 간선만 따라가며 DFS로 유량을 흘린다.
3. 한 번의 BFS에서 가능한 유량을 최대한 흘려 **blocking flow**를 만든다.
4. 더 이상 흘릴 수 없으면 다시 BFS로 새로운 레벨 그래프를 만든다.
5. 일반 그래프 기준 시간복잡도는 **`O(V²E)`**이며, 실제 대회에서는 에드몬드-카프보다 훨씬 빠른 경우가 많다.
