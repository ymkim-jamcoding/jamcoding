# 개발 환경 세팅
- IDE 설치하기 (택 1)
	- [Visual Studio Code](https://code.visualstudio.com/download)
		- 코딩을 주로 한다면 추천
	- [Antigravity](https://antigravity.google/download)
		- 초보자에게 추천
- node.js 설치 (for window)
	- Node란?
		- javaScript는 브라우저(크롬, 엣지, 오페라 등)에서 동작되는 코딩 언어. 로컬 컴퓨터에서도 실행될 수 있게끔 해주는 런타임 프로그램
	- [Node.js](https://nodejs.org/en/download)
		- ![[image-바이브 코딩.png]]
	- 설치 후 `powershell` 에서 node가 잘 설치되어있는지 확인하기
		- `node -v`
		- `npm -v`
- git 설치
	- [Git](https://git-scm.com/install/windows)

# 기본 프로젝트 만들기
- IDE에서 프로젝트 시작할 폴더 열기
- 기본 뼈대 만들기
	- ```shell
		npx create-next-app@latest . --yes
		```
		- [CLI: create-next-app \| Next.js](https://nextjs.org/docs/app/api-reference/cli/create-next-app)
- 내 컴퓨터에 임시 서버 띄우기
	- ```shell
		npm run dev
		```

# DB 연결, 로그인(Oauth)
- [supabase](https://supabase.com/)
	- 새 프로젝트 생성
	- supabase mcp 연결
		- [Model context protocol (MCP) \| Supabase Docs](https://supabase.com/docs/guides/getting-started/mcp)
		- `cmd + k` , type `connect via MCP`
	- vibe
		- `supabase mcp 연결이 되었니?~`
	- 로그인 설정
		- Authentication -> Sign In / Providers ->google ...
	
- [google oauth](https://developers.google.com/identity/sign-in/web/sign-in)
	- https://console.cloud.google.com/auth/clients
		- new project
		- api service -> user auth info -> oauth client ID -> create
		- clients -> select current project -> Authorized JavaScript origins, Authorized redirect URIs
	- `Clients Ids`, `Clients Secret`
